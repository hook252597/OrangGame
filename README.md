# 🍊 OrangGame — 오렌지 타이쿤

귤나무 한 그루로 시작해 **누적 매출 1억 원**의 오렌지 제국을 세우는 웹 타이쿤 게임입니다.

▶ **플레이:** https://hook252597.github.io/OrangGame/

## 게임 방법
- 🌳 나무를 클릭해 🍊 오렌지를 수확하고, 시장에서 판매해 돈을 법니다.
- 시세는 몇 초마다 오르내립니다. ▲일 때 팔면 이득!
- 🏗️ **시설**: 귤나무 · 농부 · 과수원 · 스마트팜 · 품종 연구소 · 오렌지 섬으로 자동 생산
- 🥤 **착즙기**(🍊→🧃), 🏭 **잼 공장**(🧃→🫙)으로 가공해 더 비싸게 판매
- 🚚 **배달 트럭**: 자동판매를 켠 상품을 대신 판매
- ⚡ **업그레이드** 15종, 🎉 랜덤 이벤트(풍년·태풍·주스 열풍·축제), ✨ 황금 오렌지
- 진행 상황은 브라우저(localStorage)에 자동 저장됩니다.

## 기술
빌드 과정 없는 단일 `index.html` (HTML · CSS · Vanilla JavaScript)
